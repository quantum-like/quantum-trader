# Guardrails: master checklist for ML4T research

Cross-cutting reference compiled from the guardrail sections of every chapter, case study and library reference in this skill. This file is the index: the tag legend, the item format and a map from each catalog section to the part file that holds it. The catalog is split into three parts of roughly 10k words each so one stage can be loaded at a time, and the pre-flight questions are in `preflight.md`. Every item is tagged with its source unit(s) so the detailed reference can be opened; items that say the same thing in several chapters are merged once with all tags, and marks such as "(inference)" are carried over from the notes.

**Tag legend.** `chNN` = `chapters/NN_*.md` (e.g. `ch07` = `chapters/07_defining_the_learning_task.md`). Case studies: `cs_etfs` = `case_studies/etfs.md`, `cs_crypto` = `case_studies/crypto_perps_funding.md`, `cs_nasdaq` = `case_studies/nasdaq100_microstructure.md`, `cs_sp500eo` = `case_studies/sp500_equity_option_analytics.md`, `cs_usfirm` = `case_studies/us_firm_characteristics.md`, `cs_fx` = `case_studies/fx_pairs.md`, `cs_cme` = `case_studies/cme_futures.md`, `cs_sp500opt` = `case_studies/sp500_options.md`, `cs_usequities` = `case_studies/us_equities_panel.md`. Libraries: `lib_data` = `libraries/ml4t_data.md`, `lib_engineer` = `libraries/ml4t_engineer.md`, `lib_models` = `libraries/ml4t_models.md`, `lib_diagnostic` = `libraries/ml4t_diagnostic.md`, `lib_backtest` = `libraries/ml4t_backtest.md`, `lib_live` = `libraries/ml4t_live.md` (the same legend as `evidence.md`, `decision_rules.md` and `glossary.md`). Companion-repo paths: a bare `setup.yaml` means `case_studies/<case_study>/config/setup.yaml`; `registry.db` means `case_studies/<case_study>/run_log/registry.db`, a gitignored artifact (43–180 MB) regenerated by pipeline runs and never present in a fresh checkout.

**Item format.** **name** — what / why it matters / how to detect or prevent — (tags).

**Further reading** (literature, methods and tools named in the notes, with abbreviations expanded; author attributions appear only where the notes give them — consult the chapter references for full citations)
- AFML (López de Prado, *Advances in Financial Machine Learning*) — cited in the notes for the train-only scaler fit (ch. 7) and the run-bar definition `θ_T = max{Σ buys, Σ sells}` (2.3); the purge/embargo, uniqueness-weight, sequential-bootstrap, DSR and PBO items above rely on the ml4t-engineer and ml4t-diagnostic implementations.
- Harvey — the t ≥ 3 bar for published factors; Lo — Sharpe-ratio autocorrelation correction (a diagnostic only on short samples).
- Deflated Sharpe Ratio, Probabilistic Sharpe Ratio and Minimum Track Record Length — as implemented in ml4t-diagnostic (`deflated_sharpe`, `compute_min_trl` / `min_trl_fwer`).
- Newey-West; Driscoll-Kraay — HAC and panel-robust standard errors.
- Benjamini-Hochberg (`benjamini_hochberg_fdr`) and Holm — FDR/FWER control; Massart / Rademacher complexity — the RAS haircut.
- Lee-Ready — trade classification; Kyle (1985) — lambda (the library `"ratio"` default is not the Kyle slope); CS (Corwin-Schultz) and Roll — spread estimators; Almgren-Chriss — optimal execution.
- Ledoit-Wolf — covariance shrinkage; Kupiec — VaR exception test; Cornish-Fisher expansion.
- BMP (1991) and Corrado — event-study tests.
- Feng-Giglio-Xiu — factor-zoo cross-sectional SDF loadings; PCMCI / Tigramite and NOTEARS — causal-discovery tools.
- Lopez-Lira — testing LLM forecasters on questions inside their training data; Neyman extremization in forecast aggregation.
