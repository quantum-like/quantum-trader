## 1. Data acquisition and storage

- **Vendor close ambiguity** — WIKI close is raw, Yahoo may be split-adjusted and varies by interface, the ETF panel close is fully adjusted / the same number means different things per provider, so returns and dollar floors silently change meaning / test on AAPL 2014-06-09 7:1; name the convention per number; Alpaca `adjustment="raw"` by default, Tiingo exposes raw and adjusted; detect discontinuities at split dates (ch02, lib_data).
- **Adjustment-basis mismatch when stitching providers** — Yahoo adjusts through today while WikiPrices stops 2018-03-27; stitched histories carry a false seam / a day's move baked into the rescale factor, double-counted seam rows, a stitch that silently needed no overlap / rescale on a shared date (volume by reciprocal), never measure the factor across the seam; `raise ValueError` on silent no-overlap; filter each leg on the seam date and print row counts; carry `source` + `processed_at` columns on multi-source panels (ch02, lib_data).
- **Half-formed current bar / in-progress session** — Yahoo returns volume with null OHLC for the forming bar (`DataValidationError: yahoo: Column 'open' contains 1 null values`); placeholder resolution is not calendar-predictable (AAPL still NaN 8.5 h after close) / intra-session data leaks into features and sizing / `_drop_priceless_rows`, `update_through_last_complete_bar`, retreat loop that stops when `end <= last_stored`; keep only sessions strictly before the current UTC date and reconcile against raw counts; `ProviderUpdater(safety_margin_minutes=5)` backs the end time off so an in-progress bar is not stored as final (inference) (ch02, ch25, lib_data).
- **Forward-filled gaps** — `DataManager.update(fill_gaps=True)` default writes hundreds of phantom weekend/holiday bars / invented observations / `fill_gaps=False` or the safe helper; `complete_sessions(fill_method="forward", zero_volume=True)` writes zero volume so synthetic rows stay identifiable (ch02, lib_data).
- **Gap detector without an exchange calendar** — holidays read as 1-day gaps, calendar-dense series report none, wrong cadence threshold per market / pair with a calendar-aware completeness check; `GapDetector(tolerance=0.1)` flags intervals > expected + 10% (inference) and suppresses overnight/weekend false positives; `CryptoCalendar.find_gaps(threshold_multiplier=1.5)` excludes maintenance windows; set the gap threshold in the break of the step distribution (5 days), universe-wide gaps are market events (ch02, lib_data).
- **Vendor revisions after first store** — Yahoo revises ~5 trading days, CRSP ~30 / stored history silently stale / `update(lookback_days=7)` overlap keeping newest; `FULL_REFRESH` instead of patching parquet in place; `--update` extends past a drifted `end:` config (ch02, lib_data).
- **Non-atomic writes and torn reads** — a crash mid-write corrupts the store / `atomic_write_parquet` (`.tmp` then `replace`); HiveStorage generations; stage → rename into `generations/` → fsync → commit manifest; single-writer `FileLock` per key (`lock_timeout=30.0`); `atomic_writes=False` rejected (ch02, lib_data).
- **Validator that only passes** — a check that cannot fail hides defects / inject faults; confirm the sort-monotonicity check fires on a deliberately shuffled frame; a leakage test built on a frame already filtered by the same condition only tests Polars (ch02, ch07, ch23, cs_cme).
- **Per-fetch schema and value integrity** — missing canonical columns, nulls, wrong dtypes, NaN/inf, negative volume, OHLC invariant violations (`ohlc_mode="strict"` raise / `"drop"` logs `n_dropped` / `"warn"`), duplicate `(timestamp, symbol)`, symbol identity mismatch all raise `DataValidationError`; FRED/Kalshi/Polymarket skip OHLC checks only / silent instrument drift otherwise / set `provider.ohlc_mode="drop"` for noisy sources; `StorageManager.load/update(enable_validation=True)` (lib_data).
- **Post-load screening presets** — `OHLCVValidator` (staleness 5 identical closes, `|return| > 0.5`), `CrossValidator` (gap > 10%, volume > 10x, weekend bars, outside 9:30–16:00 ET), `AnomalyManager` (MAD/z/IQR threshold 3.0, `min_samples=20`, `max_unchanged_days=5`); class presets equity 0.2/5/10.0/0.05, crypto 0.5/3/20.0/0.15, forex 0.1/10/5.0/0.02, commodity/futures `negative_price_policy="warn"` 0.15/5/8.0/0.05 / one threshold across MAD/Z/IQR is three cutoffs; extreme-return WARNINGs flag each series' largest real move / print cutoffs in return units; score flags against corporate-action columns; read `report.has_critical_issues()` (ch02, lib_data).
- **Phantom sessions and holiday-dated rows** — LFVN/END print on holidays; provider rows dated to holidays / fake trading days / keep sessions with ≥ 20% of the universe quoted; `MIN_SYMBOLS_PER_DATE=1_000` defines a market date (lower for subsampled panels) (ch02, ch23).
- **Price units and scaling** — ITCH price4 (/10000), DataBento nanodollars (/1e9), CHRIS cents vs dollars scale P&L 100x; futures `quote_scale = tick * contract_size / tick_value ∈ {1, 100}` / silently wrong magnitudes / heuristics median > 10000 or > 1e6; print min/median/max; `_normalize_price_units`, `ContractSpec.__post_init__`; read `tick_size`/`tick_value` from `data/futures/market/futures_specs.yaml` (ch03, lib_data, cs_cme).
- **Futures contract-data hygiene** — a hand-written `ASSET_CLASS_MAP` silently skips unmapped products; roll counts mixing tenors (deferred tenors flip often); bar length assumed from an argument name; different bar lengths joined on a bare timestamp; calendar spreads inside contract data (single-digit negatives, high volume); last trade ≠ expiry for thin listings; "5 days before Friday" counted in calendar days lands on Sunday; inner joins swallow uncovered days; episodes numbered on disagreeing rows only halve lengths; roll convention mattered least in zero-rate years / raise on unmapped products; count rolls on the front month only and report it separately; `describe_bars` first; collapse to a common grid before joining; `MIN_OUTRIGHT_PRICE` floor; third-Friday filter; session grid folding Sunday onto Monday; anti-join and report uncovered days; keep the no-rollback guard but do not credit it (count leader ≠ front days); the handover gap grows ~10x as financing − dividend yield widens, so measure it by year in bps (ch02).
- **Options chain data hygiene** — non-solved IVs are ~1/3 of rows; stale hand-written solver code tables (~10 codes, not 5); a spread model fitted to the median is p90 > 2x off in the wings; a constant risk-free rate across 2020 (the 1y fell > 1 pp); validating on `head(n)` (all 2 January); European formulas on American contracts; silently dropped solver failures; skew read off calls alone (the left half is ITM calls); thresholding Greeks bounds hides the informative theta line; 5-day overlapping windows (effective n ≈ 1/5); eight names in one year is not a cross-section; correlation summarises a non-monotonic quintile shape wrongly / filter `Converged`, never a time-value proxy; read code tables from the data; calibrate the spread model to the tail; per-date rate; seeded random sample and print days covered; express residuals as a `delta_error/gamma` spot gap and do not attribute them; count dropped failures; read skew from the put-call gap at the same strike/expiration; report share and count; non-overlapping subsample (ch02).
- **Timezone confusion** — ITCH is naive local never UTC; DataBento needs `replace_time_zone("UTC").convert_time_zone("America/New_York")` before RTH; a fixed UTC window is an hour wrong half the year; funding-hour checks in the wrong zone miss every window / naive → treat as UTC, aware → convert to UTC before comparing to 00/08/16 UTC; bound exchange dates in `America/New_York`; `assign_sessions(outside_session="raise")` to catch bad timestamps (ch02, ch03, ch25, lib_data).
- **Crypto funding and premium mechanics** — `F = P + clamp(I − P)`: the clamp is not a cap (realized rates run many times beyond ±(I ± c); the real cap is per contract) and is not applied to the premium (`clamp(P) + I` removes the dead zone); mean premium negative while mean funding positive; the premium close is not the funding rate (Binance uses a time-weighted average); exact zeros are not missing (1 in 7, up to 1/3 on thin contracts); an exact-timestamp join across frequencies matches 1 in 8; an as-of null count read as coverage (one symbol > 2 months stale); gap checks on the reference symbol only; premium units in decimals / score against realized rates and read funding direction from realized, never from the premium sign; do not filter zeros, choose tie handling; as-of join; staleness from the publication clock; run gap checks on every symbol; label "APY above threshold" and "clamp binds" separately; scale premium units explicitly (ch02).
- **Timestamp units and dtypes at joins** — Polars µs vs pandas ns; deep-learning prediction sets carry `us`, other families `ms`; a join on mismatched dtype returns empty with no error / `dt.cast_time_unit("us")` before joins; cast with `on_clock_dtype` at every join site; `dt.replace_time_zone("UTC")` before casting a naive column; never re-key the registry (`value_digest` is unit-sensitive) (ch03, cs_crypto).
- **Sequencing ties** — multiple messages per nanosecond; Polars does not preserve input order on tied keys / deletes applied before adds / sort `(timestamp, tracking_number)` / `(ts_event, order_id)`, deletes last explicitly (ch03).
- **Parameter caps and sample limits distort diagnostics** — `MESSAGE_LIMIT`/`MAX_MESSAGES` truncate each type independently; a capped `MAX_SYMBOLS` run ranks cross-sectional statistics within a different universe (a different quantity, not a smaller one); capped 04 vs 05 frames select different names / trust only complete days; run production with `MAX_SYMBOLS=0`; `apply_max_symbols` must reach every consumer; CI reads capped matrices for shape only (ch02, ch03, cs_nasdaq, cs_usequities, cs_usfirm).
- **Derived data and output locations** — writing into `ML4T_DATA_PATH`; deployment artefacts mixed into the research registry; `Study.activate()` rewrites `ML4T_OUTPUT_DIR` process-wide / wrong registry read or written / write to chapter `output/`; open the study as the first statement before any `get_case_study_dir`, registry read or `BacktestExplorer`; `read_only_study` in reporting notebooks; glob sources from `REPO_ROOT` (ch03, ch25, cs_etfs, cs_nasdaq, cs_sp500eo, cs_usfirm).
- **Provider resilience and metered cost** — rate limits (Alpaca 200/min, FRED 100 of 120/min, Kalshi ~10/s, Polymarket 60/min CLOB + 30/min Gamma, Yahoo chunks of 50 with 1.0 s delay, Binance `max_concurrent=5`); circuit breaker opens after 5 consecutive `NetworkError`, half-open after 300 s; pagination cursors must progress; `validate_routes` refuses unroutable batches (`ProviderRoutingError`) / silent partial downloads and runaway spend / `estimate_cost()` / `--estimate-only` before any metered spend (`databento_acknowledge` requires `I UNDERSTAND`); `fail_on_partial`, `return_exceptions=True`; one provider instance per run (~30 ms httpx init) (ch02, lib_data).
- **Feed coverage** — Alpaca `feed="iex"` is ~2–3% of US volume (volume features biased low) / use `"sip"` (free plan lacks the last 15 min); unknown feed or bad `asset_class` raises at construction (lib_data).
- **Live queries in reproducible notebooks** — runs differ; CoinGecko doubles the last date; live search indexes move / `LIVE=False`, `RUN_LIVE_LLM=False`, replay from frozen logs; shipped snapshots; loaders raise `DataNotFoundError` naming the download command; `unique(subset="timestamp", keep="last")` (ch04, ch22, ch24).
- **Metadata and derived-column drift** — metadata falls behind data; `YIELD_CURVE_SLOPE = DGS10 - DGS2` duplicates `t10y2y`; derived columns drift from their formula / double weight, wrong values / `reindex` columns against metadata; recompute from inputs and compare to the metadata formula; run `duplicate_pairs`, `(df.diff() == 0).mean()`, PCA and Ward first-merge checks on any panel assembled by coverage filter alone (ch01, ch04).
- **Mixed native frequencies and trending levels** — quarterly series repeated monthly fake persistence; CPI/GDP levels make elapsed time the dominant variance direction (partition = calendar eras; extended model 4 episodes, 0 revisited) / check `native_frequency` and staleness share; enter trending series as YoY rates; check `episode_count` and `revisited_clusters`; silhouette rewards the failure (ch01).
- **Month-stamping error in resampling** — `group_by_dynamic(label="right")` stamps January as 1 February, so every downstream date is a month late / apply `offset_by("-1d")`; keep right labelling for honesty (ch01).
- **Blanket warning suppression** — `warnings.filterwarnings("ignore")` hides convergence, dropped-alt-text, sortedness and numerical warnings / scope by message, category and module (`FutureWarning, module="mlflow"`; the one LightGBM feature-name message); catch `ConvergenceWarning` into a grid column instead (ch02, ch09, ch12, ch13, ch17, ch26).
- **Benchmark hygiene** — memory-mapped reads, warm caches, truncated results posting the fastest time, acknowledge-early engines, timing the wrong operation (kdb+ `-8!` looked ~40x faster), aggregation semantics drift, size columns as compression ratios, client cost inside write bars (`iterrows` 10x `itertuples`), arithmetic mean of speedups, mismatched memory units (`estimated_size("mb")` is MiB), environment-dependent numbers / wrong engine chosen / state the cache policy; poll to queryable inside the timing; `uv run` and print versions; compare sizes only in one place; catch `Exception` not just `ImportError` for optional engines (ch02).
- **Logging noise** — `AQRFactorProvider` structlog output drowns load cells / `structlog.configure(wrapper_class=structlog.make_filtering_bound_logger(logging.WARNING))`; `MetadataTracker.check_health(stale_days=7)` for staleness (ch01, lib_data).
- **Credentials, paths and secrets** — plain-text secrets, credential URLs in errors, symlink escapes, `../x` keys / `validate_secrets`, `${ENV}` references only, owner-only YAML, `PathTraversalError`, `contained_path`; load env credentials only when `SUBMIT_PAPER_ORDERS=True` with an explicit `no_credentials` disposition; `EDGAR_IDENTITY` required (ch04, ch25, lib_data).
- **Synthetic fallback when real data are missing** — a demo that invents a corpus or panel publishes indistinguishable fake numbers under real headings / fail loudly: `load_documents` raises, 07 load failure is fatal, treat the log-normal fallback as demo-only (ch05, ch15, ch22).
- **Cache and artifact drift** — existence-keyed caches, edited parquet, regenerated corpora, stale DML or MLflow stores / old numbers under new source / signature-keyed caches (`assess_cache`, `_cache_is_usable`, `RETRAIN=True`); `.meta.json` / `.digest.json` sidecars with content hash, row count, keys, writer, input digests and estimation schedule; `EXPECTED_INPUT_SHA256`; assert `MARKET_DATA_DIGEST` across stages; `shutil.rmtree(MLFLOW_DIR)` before `set_tracking_uri` (ch11, ch15, ch22, ch23, ch26, cs_cme, cs_usequities).
- **Papermill parameter injection** — constants derived inside the tagged cell run on defaults; trailing comments hide the name so a reduced run trains at production size / derive dependent constants in a later cell; no trailing comments on `MAX_TRAIN_STEPS`/`MAX_EVAL_SAMPLES`; keep request and resolved names distinct (`resolved = injected or declared`) (ch08, ch10, cs_sp500eo).

## 2. Point-in-time, survivorship and identifiers

- **Survivorship via backfilled snapshot or chosen universe** — WIKI symbols alive at collection backfilled to IPO (exits only from ~2014); Yahoo returns live tickers; hand-picked ETF/CME/crypto lists exist today; current-constituent rosters exclude every departed company / inflated results, wrong sign on survivorship studies / detect entries/exits per year and exit span < 80% of panel span; CRSP/Compustat with delisting returns for long spans; declare "describes these surviving funds"; never claim a survivorship-free estimate; PIT eligibility removes bias within the list, not of the list (`eligibility_note`) (ch02, ch08, ch11, ch14, ch15, ch16, ch17, ch18, ch19, cs_etfs, cs_fx, cs_crypto, cs_sp500eo, cs_usfirm).
- **Full-sample liquidity or volume screen** — later volume decides historical membership; admits exactly the stocks that stayed liquid / lookahead + survivorship / `turnover = traded_close * traded_volume`, keep (symbol, year) with `n_days >= 200` and `avg_turnover >= 10e6`, `eligible_year = year + 1`, write `eligibility.csv`; `close > 5` and `adv_21d > 1M` on a trailing 21-session window per decision date; fix `UNIVERSE_END` before any fold; dollar floors on traded prices never adjusted close; thresholds not inflation-adjusted is a known limitation (ch11, ch14, ch18, ch23, cs_etfs, cs_usequities).
- **Period-end keying for fundamentals and filings** — a 10-K is filed 1–3 months and a 10-Q ~40 days after period end; text is not public until acceptance / uses numbers nobody had; the error equals the reporting lag / carry both dates; filter and ASOF-join on `announcement_date`/`filing_date` with frames sorted `[symbol, date]`, `by="symbol"`; measure `filing_date − period_end`; count rows with null knowledge time (ch04, ch08, ch10, ch22).
- **XBRL concept keying and filing-lag populations** — ASC 606 moved revenue to `RevenueFromContractWithCustomerExcludingAssessedTax`, so a null concept is a tagging change, not a missing disclosure (imputing recovers nothing); keying on labels ("Net sales" vs "Revenue") breaks cross-company joins; filing lag has two populations (routine filings vs restatements) so the mean describes neither; original + amendment summed reads as extra coverage / measure coverage per concept and read the null pattern (industry-wide = tagging) before imputing; key on us-gaap concept names (Frames API) for cross-sectional work, labels only for single-company exploration; histogram the lag (20-day bins to 800 days) and read median and tail separately, treating late-attributed facts as knowledge-time-late; count a cell once if > 0 (ch04).
- **Ranking on knowledge time instead of valid time** — returns the most recently announced row; restatements walk the answer backwards / sort `[entity, valid_time, knowledge_time]`, take last per entity (ch04).
- **Filing date vs intraday acceptance** — after-close acceptance is tradeable next session; date-only matching leaves a residual one-session look-ahead (inference) / carry `acceptance_datetime`; shift to next session if acceptance > close or use next-day open (ch04, ch10).
- **Macro period stamps, lags and revisions** — FRED stamps the first day of the reference period, pre-forward-filled (unemployment disagrees with release-lagged 3 days in 4, > 10 points in spring 2020); FRED serves the latest revision / the value read for 2008 was not visible in 2008; revised values flatter backtests / re-date to period end + agency lag (set lags at the late end of the agency range); backward `join_asof` on `published_on`; `load_macro_initial_release()` (ALFRED, `data/macro/download_alfred.py`), `vintage_date=` queries; `conservative_lag=30` for monthly series; shift Treasury timestamps `+1d` before `join_asof(strategy="backward")`; check matched-observation age `<= MAX_SLOPE_AGE_DAYS=4`, not row count; descriptive use only otherwise, and flag as limitation (ch01, ch02, ch04, ch08, ch14, ch16, ch19, lib_data, cs_etfs).
- **COT report-date keying** — Tuesday positions publish Friday after close; CFTC holiday releases are not fixed offsets / ~3 days of future positioning / `available_from = report_date + 7d` or `attach_cot_release_schedule(cot, official_schedule)` then `combine_cot_ohlcv` (as-of on `available_at <= timestamp`); z-score windows in reports (52 = 1 year); `rolling_std(26).shift(1)`; null when std == 0; several CFTC markets per product code double-count (keep the deepest open interest per date); only three of five categories do not sum to zero (measure the five-category identity, call "speculator movement" a partial view); the asset-manager sign is net long every week (use size/z-score, not sign); contrarian rules across products are not diversification until z-scores are correlated on shared report dates (ch04, lib_data).
- **13F availability and partial quarters** — positions are as of quarter end but observable only on filing dates (≤ 45-day lag); inside the window the newest quarter holds early filers only, so missing peers look like liquidations / `timestamp = max(filing_date)` per period; admit a quarter only when `n_ciks == covered_ciks` / `institutions == PANEL_SIZE`; compute coverage before dropping `put_call` rows; test by withholding one institution's newest filing (ch04, ch22, ch23).
- **13F parsing and scope** — sorting by accession number ranks filing agents, not dates; bulk unit errors imply tens of thousands $/share and carry trillions; 13F is not AUM or the full book (long-only US-listed equities/ETOs, ≤ 45-day lag; shorts, foreign, cash, debt absent); option rows summed with stock; grouping by free-text issuer name (thousands of CUSIPs have multiple spellings); breadth as crowding unweighted ($100 and $1bn count the same, index funds hold everything); bulk positions are ≥ 6 weeks old / latest `filing_date` per CIK; keep the median implied price per filing in [$1, $10,000] and report count and value removed per bucket; say "reported 13F value"; filter `put_call == ""` before portfolio shares; group on CUSIP (`issuer.mode()` for legibility only); weight by value or restrict to concentrated managers, deliberately; per-CIK filings as they land for reaction, bulk for the cross-section (ch04).
- **Ticker reuse and ticker-keyed joins** — HERO/EXXI relisted, ZOOM/ZM 2020, FB in 2020, dual share classes index one filing twice / two companies joined, duplicates counted as corroboration / detect gains > 100% with `split_ratio` silent and zero prior volume; key on CIK/LEI/CUSIP/`sec_id`; dedupe on `accession_no`; alias table with validity dates; assert per-symbol coverage (ch02, ch03, ch04, ch22, ch23).
- **Entity resolution** — wrong match contaminates every statistic with no flag; legal suffixes inflate every score; rule-of-thumb thresholds; aliases without validity windows; 82 of 133 subject strings were re-spellings / prefer no match; sweep `THRESHOLD_GRID` with precision/recall on non-matchable rows (70 chosen here); strip suffixes repeatedly before scoring; assert `n_unique == len` and unchanged row count after each join; canonical key + filer roster; `MERGE (:Entity {name})` with role as a second label; `is_actionable_entity`; subsidiaries need a corporate hierarchy (ch04, ch23).
- **Carry-forward across a security-identity change** — a dead security's last IV carried into whoever picked up the ticker; volume z-scores restart / phantom continuity / apply lag and fill `.over("sec_id")`; compute returns per security-identity segment; `pl.col("session").diff().over("sec_id") == 1` (cs_sp500eo, cs_sp500opt).
- **Delisting handling** — delisting rate alone is not evidence; terminal returns on the delisting date double-count premiums; a tight Monte Carlo band read as certainty / measure terminal = 0; exit-span check; assumption spread is 10x larger than the band (ch02).
- **Corporate-action detection by threshold** — the 25% overnight rule recalls all splits but ~1/3 of flags match no action (GOOGL Class C ex-dividend, earnings crashes); `|r| > 1` as a detector never fires on forward splits (returns are bounded at −1) and most flagged rows are not splits; an unadjusted action inside an "adjusted" column (PCO 1:100 reverse split 2017-12-05: one 200x row moves a 2,000-name EW portfolio by double digits and flips the survivorship sign) / use a corporate-action feed and `split_ratio`; adjust upstream before quarantining real market moves; drop `ret > 1.0` or `prev_volume == 0` BEFORE any survivorship check; investigate flagged extremes, use the threshold only as a filter for implausible upward jumps before scaler fitting (ch02, ch07).
- **Non-causal fills** — interpolation, backward fill, centred moving averages (~half the window in the future), whole-sample seasonal adjustment, pinned prediction-market zeros repaired backward / read the future silently / forward fill, trailing stats, causal forecasts only; null `close == 0 & high > 0` then forward fill within symbol (ch02, ch04).
- **Calendar-day grid mistaken for trading grid** — weekend rows carry Friday's value; 252 rows = 8 months on FRED; a 21-day label buffer passed as a Timedelta is ~15 trading sessions; 35 calendar days read as sessions purges ~7 weeks; a 21-calendar-day purge is ≈ 14 sessions, so ~7 sessions of a 21-session label still leak / wrong windows and under-buffering / declare windows in calendar days or move to the trading grid; pass the market calendar (`calendar="XNYS"`) and integer sessions; `buffer_unit: calendar` declared explicitly; `embargo_from_buffer(buffer, observed_step=cadence)` (ch04, ch06, ch08, cs_etfs, cs_cme, cs_sp500opt).
- **Forward-filled slow data inflates sample size** — each quarterly observation repeats ~63 trading days; rolling stats over filled rows weight weeks by days occupied / false precision / count value changes per year; compute stats on releases then as-of join; compute the empirical inflation factor; prices LEFT in any macro join and count unattached rows (ch04, ch08).
- **Monthly characteristics joined to daily prices** — a naive join leaks future characteristic updates into earlier days / as-of join on `dt.truncate("1mo")`; `join_asof(strategy="backward")` on sorted keys, never `forward`; an exact-timestamp inner join only for same-frequency panels (ch07).
- **Stale characteristics carried across a symbol gap** — joining by shifting rows pairs old information with a new return whenever a symbol has a gap / join on a global trading-date map per symbol and drop gaps; create a label only if the symbol has a price on the exact target date (ch14).
- **Restated feeds with no vintages** — today's 2021 TVL includes protocols nobody tracked in 2021 / hard gate: block; start daily snapshots; restrict claims to the snapshotted period; composite scoring must not let a strong signal outvote a failed gate (ch04).
- **Extraction-time leakage in graphs** — every edge comes from one extractor run more recent than any cutoff; a disclosure filter cannot fix it / backtest reads a graph that did not exist then / keep each run's edges under its extraction date or refuse edges until `extraction_time <= cutoff`; on a single-run graph say there is nothing to trade on (ch23).
- **Model, checkpoint and search cutoffs** — `ProsusAI/finbert` fine-tuned on all of PhraseBank; TSFM pretraining corpora overlap evaluation windows; web search returns resolved answers / contamination no split can detect / read model cards, carry provenance as a column, evaluate only post-cutoff data; `cutoff_date` in the `SearchClient` contract plus a consistency gate; partition dated vs undated results (chapter captures had 0 dated of 40) (ch10, ch13, ch24).
- **Pre-shifted panels and encoded ranks** — characteristics already ranked in [−0.5, 0.5] and already lagged; shifting again or reading a rank as a level fails silently / assert the encoding at load; read alignment out of the data (`ST_REV` vs label +0.904 at previous row, −0.028 own row); assert the label is null exactly on each entity's last period (cs_usfirm).
- **Eligibility relative to the holdout** — names first quoting inside the holdout trade at a never-measured cost / require at least one session before `holdout_start`; assert the declared list against the archive in both directions (cs_nasdaq).
- **Identifiers across splits and positions carried over boundaries** — academic panels offset ids by a million per split / never carry a position across a split boundary (ch04).
- **PIT roll selection for futures** — rank-based rolls must pick by the PREVIOUS observation's volume/OI (`_lagged_rank_selections`); `VolumeBasedRoll(min_days_between_rolls=20)`, `TimeBasedRoll(days_before_expiration=5, use_business_days=True)`, `FirstNoticeDateRoll(days_before_first_notice=1)` / switch date equal to the first day the new contract leads is lookahead; one-digit year codes (`ESM1`), `parse_contract_symbol(reference_year=)`; capture date read as listing date; ratio-adjust per (product, tenor) before aggregating; carry/term structure from `raw_*` never from adjusted levels (ch02, lib_data, cs_cme).
- **`APPEND_ONLY` vs other update modes** — `APPEND_ONLY` keeps published history immutable (PIT-safe, inference); `INCREMENTAL` replaces overlaps keeping newest; `FULL_REFRESH` replaces the key; `BACKFILL` fills detected gaps only (lib_data).
- **Feature-store as-of join is not publication-aware** — `join_asof(strategy="backward", tolerance)` guarantees only `feature.timestamp <= label.timestamp` / it prevents lookahead only if the stored timestamp is the time the value became KNOWN (publication time); the library does not shift by publication lag / shift to availability in `ml4t-data` or the caller before storing (lib_engineer).

## 3. Microstructure and bars

- **Order-book reconstruction errors** — replace chains lost (U issues a new reference absent from adds), deletes sized at original shares (double-count partial fills, negative levels), cold-start books hitting unknown pre-market references, C executions ignored, P/T prints applied to the book / corrupt depth and OFI / keep a live pool updated by U or pointer-double chains with a cycle cap; size deletes as `shares − removed_before` with deletes sorted last; process from start of day and print `unknown_order_count`; include C in removals; P (ITCH) and T (DataBento) are tape only, F updates the book; count `(spread < 0)` as the reconstruction error rate (ch03).
- **Unsigned integer subtraction** — UInt32 `100 − 200` wraps to 4,294,967,196 / absurd OFI / cast to Int64/float64 before any imbalance arithmetic (ch03).
- **Trade-side classification** — ITCH P side is always 'B' (resting side) so signed bars degenerate to tick bars; DataBento side N unlabeled; tick rule misclassifies trades inside the spread; tick rule applied on bar close collapses OFI to the sign of the bar return / infer with tick test or Lee-Ready and assert both sides present; print the unclassified share and build every bar type from the same classified set; classify per trade inside `aggregate_to_bars`; prefer quote-based classification when quotes exist; apply ~1 ms (co-located) to ~10 ms (retail) lag for Lee-Ready in backtests; print coverage beside tick-test accuracy (ch03, ch08, ch18).
- **Bad prints and sentinels** — pegged/far adds at ~0 or 1e5, bad ITCH prints, late-reported TAQ trades (condition `80000002` carries the prior close), zero-price NBBO sides, locked/crossed quotes, vendor sentinel values for failed IV solves / extreme false returns and spreads / read p1–p99 not min/max; winsorize returns p1/p99; range as `(p95 − p5)/median`; drop by condition code plus symbol-day band; filter `price > 0`, `spread > 0`, `spread_bps < 500`; drop crossed/non-positive quotes; normalise sentinels at the loader (ch03, ch18, cs_nasdaq, cs_sp500eo).
- **Session blending** — pre/post-market flattens the U-shape, inflates spreads and dominates flow regressions / filter RTH first (`regular_session_mask()` 09:30–16:00 ET); report null rates by session; never impute minute-bar trade fields (~20% null with extended hours); bound sessions by the published schedule and drop bars stamped after the scheduled close (vendor padding on early-close days feeds padded exit prices) (ch03, ch18, cs_nasdaq).
- **Trade-price returns and stale quotes** — bid-ask bounce gives mechanical negative AC(1); trading against a stale quote attributes volume to the wrong side / use NBBO midpoint returns; tolerate at most `stale_cap: 5` consecutive stale-quote bars then null; sanity-check quote extremes before short-window variance features (inference) (ch03, cs_nasdaq).
- **Adaptive imbalance-bar threshold spiral** — EWMA of E[T] and P[b=1] fed from the sampler's own bars; one-sided flow (NVDA 52–60% buys) raises thresholds → longer bars → higher estimates, or collapses to one trade per bar / unusable bars / alpha=0.001 (not 0.1), warm-up 100, `FixedTickImbalanceBarSampler` in production or window samplers; diagnose via bar count, average bar size, `et_drift`, `expected_t x expected_imbalance` bar by bar; library samplers hold `min_bars_warmup=10` with EWMA `alpha=0.1`, `include_incomplete=False` drops the trailing partial bar; drop the first ~10 adaptive bars (inference); run bars use `θ_T = max{Σ buys, Σ sells}` over the whole bar, not consecutive runs (ch03, lib_engineer).
- **Sampler calibration** — TIB thresholds in trades, VIB in shares (TIBs give ~800x more bars at equal E[T]); single-day calibration ignores large daily volume CV; volume thresholds after a price move / incomparable bar counts / calibrate each sampler on its own grid across days off the median day; prefer dollar bars; fixed-sample-count CV is wrong for activity bars (65K–100K rows/week); sessions are atomic in splitters (ch03, lib_diagnostic).
- **Markout and signal-without-cost** — contemporaneous correlation read as signal; in-sample nb-03 correlations have no holdout; latency-adjusted markout at h = latency is zero by construction / lag the predictor `ofi.shift(1).over(session)`; compute midpoint, latency-adjusted (`LATENCY_BARS=1`) and executable markouts; compare decile spread to ~1–2 bps round trip; report h > LATENCY_BARS only; signed log `sign(x) log1p(|x|)` for heavy-tailed OFI; `MIN_BUCKETS=50` and a fixed stratified 50-symbol cross-section (ch03).
- **Jump detection** — a test bridging overnight reads the gap as a jump; per-bar significance yields false jumps daily; naive |z| > 4 with daily sigma over-detects calm days / compute per (symbol, date); Gumbel critical value with `C_n, S_n` from median session length; local bipower sigma (ch03).
- **Order-lifetime statistics** — partial-fill-then-delete counted in both rates; replace counted as cancellation; whole-second durations zero sub-second lifetimes; right-censoring at the close; venue-wide vs per-symbol definitions / one-outcome-per-order on the first event; break termination down by D/X/U; `total_nanoseconds()/1e9` with log-axis histograms; report "still live or unknown"; never compare venue-wide and per-symbol directly (ch03).
- **Bar index is not the clock; un-normalised averaging** — label by `slot_label(time_slot)`; express each ticker's bars as a share of its own daily total before averaging (ch03).
- **Observation grid from spacing, not config** — dividing a duration by `decision.bar_frequency` made embargoes, permutation blocks and period counts 15x too small (`allocator_lookback: 520` is 520 minutes; `hold_bars`, `bars_per_day`, `time_exit` count 1-minute rows) / measure the grid from timestamp spacing; bound every trailing window by the symbol-session and restart warm-up each session (cs_nasdaq).
- **Session boundaries that cross midnight** — CME sessions open 17:00 CT; FX rolls at the CME_FX 5PM; UTC days mislabel P&L and put ~a third of each day in the wrong row / `SessionConfig`, `compute_session_pnl`, `decision.session_calendar`; detect via hours-of-day and one-bar-day counts; FX Sunday reopen bars ≥ 21:00 UTC are not anomalies; verify crypto bars sit on 00/08/16 UTC; Dec 24/31 close the whole FX universe (three-way gap taxonomy) (ch02, ch07, ch16, cs_fx).
- **Stale "last bar" snapshots in a cross-sectional panel** — falling back to each instrument's last observed bar fills a missing price with an earlier one; the panel stops being one instant wide and the decision timestamp silently moves / derive the decision timestamp from the calendar, check it against the declared close, count quoting instruments at that exact moment (cs_fx).
- **Amihud vs Kyle lambda** — they rank by different quantities, can invert orderings and scale differently with volume units; `kyle_lambda(method="regression")` raises `NotImplementedError` and the `"ratio"` default has no sign; a single-bar |return|/dollar-volume is not Amihud / ported thresholds mislead / multiply volumes by a constant and check which moves; name the measure; call the library estimator (window average skipping zero-volume bars) (ch08, cs_nasdaq).
- **Spread or depth computed from order flow** — cancellations and executions are not in arrival flow; the book has memory / reconstruct LOB state; keep flow and state in separate feature classes; `min_spread == 0` is a stress/data condition (exclude `trade_at_cross` from OFI); FINRA share mixes dark pools and retail internalisation (condition on changes) (ch03, ch08).
- **Single ITCH session or symbol** — one day, one venue, one symbol-quarter cannot establish general behaviour / widen samples before quoting point estimates; report spans (ch08, ch18, ch21).
- **Memory and performance** — notebooks peak 13–33 GB and exceed 100 GB cumulatively; Polars arenas release only on restart / predicate pushdown, column selection, kernel restarts, `MAX_*` caps for trials, Numba buffer bounds; `Counter` price levels sorted on query; numpy arrays not `to_dicts()`; one `with_columns` call with `.over()` windows (ch03, ch07).
- **Store sentinels and caches** — creating `messages/` before parsing defeats `must_exist`; `REBUILD_ENRICHED=False` reads cache / create only when about to write; committed runs rebuild; `--smallest` IEX test symbols validate the parser only (ch03).

## 4. Labels

- **Anchor mismatch / same-bar fill** — label close-to-close but execution next open; scoring a prediction on the bar it was formed from credits a price the model could not trade; invisible in the mean, decisive per label / anchor where the fill happens (next open for EOD signals, next-bar VWAP intraday, `execution_delay: 1_bar`); pair score at close t with return t→t+1; where the release has no open price name the close-to-close label as a proxy and keep the gap in mind reading IC vs Sharpe (ch07, ch16, ch19, ch26, cs_nasdaq, cs_fx, cs_usfirm, cs_sp500eo, cs_etfs).
- **Close-only triple barrier** — touches detected only on closes and booked at the barrier price; gains understated, losses hidden (asymmetric, larger on the stop side) / pass `high_col`, `low_col`, `open_col`; library `_resolve_barrier_exit` uses the open for gap-through; `calendar_aware_labels` keeps windows inside sessions; to size the effect run a second labeling, never reprice the first (ch07, lib_engineer).
- **Barrier labels read as market description** — a −1% stop on a path that fell 28% discards the path / barriers only when the strategy really exits there; fixed-horizon returns to forecast magnitude; `reject_boolean_numeric_setting`, `validate_finite_numeric_setting`, `validate_max_horizon` (ch07, lib_engineer).
- **Class balance read as informativeness; cut-point drift** — barrier labels balance because the stop (1%) is tighter than the TP (2%); a constant class balance can hide a target whose economic meaning changes / compare against the majority-class baseline; `label_diagnostics` over time; plot the cut-point return series beside class proportions; measure the label domain on disk before choosing a metric (binary AUC on ternary `fwd_dir_8h_3c`) (ch07, ch12).
- **Overlapping labels treated as independent** — N_eff ≈ N/H (418,362 dev rows → N_eff 20,017 ≈ 1/21); naive SEs overstate by ~sqrt(overlap) (momentum naive t 5.06 vs HAC 1.44; naive +6.89 vs HAC +6.14 monthly); the loss is dominated by high-concurrency periods; on a 1-minute matrix each 15-min label is seen 15 times / uniqueness weights (`calculate_uniqueness=True`), `sequential_bootstrap`, `effective_sample_size(..., bar_col="session")` (case-study helper in `case_studies/utils/label_diagnostics.py`, not ml4t-engineer) on a grid built before any row was dropped (a label occupies h intervals, `ends = events + horizon − 1`); at the 1-day horizon the effective count must equal the row count; sample IC one observation per horizon; `labels.rebalance_step` 1/5/21 so a 21-day label is not traded daily (ch07, ch11, ch13, ch14, ch17, lib_engineer, cs_etfs, cs_cme, cs_fx, cs_usequities, cs_nasdaq, cs_sp500opt).
- **Trend-scanning t as significance** — price-level regression residuals are autocorrelated; a driftless shuffled path rejects as often as SPY / use sign/horizon; calibrate any t against a demeaned-shuffle permutation null (ch07).
- **MFE/MAE windows and excursions as features** — a window including bar t counts pre-entry movement and stretches H to H+1; entry-bar high/low inflates excursions; excursions are forward-looking ("DO NOT use excursion values as ML features") / shifts −1..−H (`shift(-1)` before the reverse rolling max); measure from the bar after a close entry; use only to pick TP/SL (ch07, ch19, lib_diagnostic).
- **Multi-tenor or multi-contract rows in forward windows** — `shift(-k)` steps across contracts, inflating excursions; `shift(21)` on straddle rows is 21 quotes not 21 sessions / filter to one tenor before shifting; keep `position == 0` before any shift; reindex onto the underlying session grid with `min_observations_fraction: 0.8` (ch07, cs_cme, cs_sp500opt).
- **Round-number barriers** — "TP = 2x ATR, SL = 1x ATR", "2% crypto": measured p75 stop for SPY/ES is > 3x ATR / ordinary movement hits the stop / calibrate from MFE/MAE quantiles per instrument and horizon using p75 of per-entry MAE(t)/ATR(t), not an aggregate ratio; recompute on each refresh; few closed calibration trades give noisy levels (priors seeding a search) (ch07, ch19).
- **Labels built after the eligibility screen** — the forward step counts surviving rows so the horizon spans removed rows / build `forward_return` on the FULL price history sorted (symbol, timestamp) before any filter; four asserts: incomplete tails null, window calendar span `<= ceil(7h/5) + 7` days, labelled rows == total − h·n_symbols, dtype Float64; reconcile every unlabelled row to one cause summing to frame height (missing exit quote, never-quoted premium, hole in hedge path, expiry past panel end) (cs_etfs, cs_usequities, cs_cme, cs_sp500opt, cs_fx).
- **Holes and settlement clocks** — a hole inside the window pairs non-adjacent sessions; funding settles on a variable 2h/4h clock; a 60-row sequence can span > 60 settlements / `MAX_SESSION_GAP_DAYS = 5`, null where `_holes.shift(-h) − _holes != 0`, reconcile `labelled + tail + hole + no-anchor == height`; time-window rolling for funding sums; quote `eligible_rows` not panel height; `session_col` forward returns null the last `horizon` bars per session; time horizons use `join_asof` with `tolerance` (cs_cme, cs_crypto, lib_engineer).
- **Label built on the wrong instrument** — shifting a constant-maturity or "30-day ATM straddle" column returns a different contract most days; zeroing roll-day returns deletes real P&L / `instr_ret_*` is not a return anyone held / look up the held contract in the raw chain at entry and exit; held-contract return with roll cost in costs; inner join legs on (date, strike, expiration); `∏(1 − r) − 1` for a short (ch02, cs_sp500opt).
- **Null comparison yields a confident class** — `null > 0` is false, not null / unfillable rows receive a direction / explicit null guard when deriving `fwd_dir_*` (cs_sp500eo).
- **Label names ≠ task** — FinMarBa labels are the sign of subsequent price moves, not sentiment; market-neutral ≠ sentiment-neutral / inspect the source column (`Pct_Change`) before scoring (ch10).
- **Window label written back across covered sessions** — puts returns up to t+h−1 on session t / `label_at_window_close`; first label index ≥ `WINDOW_LEN − 1`; earn a regime label against the next session, not the same close (ch09).
- **Shifted trailing return as forward return** — coincides only when momentum window == horizon / price at both ends of the forward window (ch04).
- **Point-in-time percentile thresholds** — `rolling_percentile_*` uses only forward returns whose horizon has ended (availability index `t + horizon`); thresholds null until `min_samples` outcomes exist (`max(1, min(1008, lookback // 10))`) / changing a future price must never alter an earlier threshold (lib_engineer).
- **Heavy-tailed or capped targets** — squared error on a capped-above, unbounded-below target lets tails dominate / compare mse vs mae/huber and raw vs winsorized (`fwd_ret_1m_win`) at fixed features and folds as separately declared experiments; attach a signal to the label it holds on (cs_sp500opt, cs_usfirm).
- **Label count ≠ horizon count; label mixing** — two labels can share a horizon; the HTM option label with coherent costs and fixed-horizon straddle labels with bps costs are not comparable / map labels to trading days (`HORIZON_DAYS`), fail on unknown labels; `LABEL_RESTRICTIONS` pins the comparison label (ch15, ch20).
- **Sizing on uncalibrated probabilities** — AUC-optimised classifiers rank but are not calibrated / calibrate before `compute_bet_size`; reliability diagram; hit rate by confidence quintile must rise monotonically (ch07, ch11).

## 5. Features

### 5a. Direct (price, volume, fundamental, macro) features

- **Unsorted data before rolling ops; re-sort after joins** — windows silently misalign; stringified dates sort lexicographically; `join_asof` with `by=` cannot verify sortedness / sort once at load `df.sort(["symbol", "timestamp"])`, re-sort after every join feeding a rolling op, assert grid spacing; `compute_features` sorts by `[*group_cols, timestamp]` (set `assume_sorted=True` only when order is truly temporal); explicit sort + assert before suppressing the sortedness warning (ch07, ch08, ch10, cs_etfs, lib_engineer).
- **Full-sample z-score, rank, winsor or scaler** — future cross-sectional moments; panel dispersion more than doubles between quietest and loudest year; composite liquidity scores carry post-bar information / `.over("timestamp")` for every cross-sectional statistic, never `pl.col(x).zscore()` on the whole column; per-date quantile clipping (`winsorize_features`, `clip_within_date` at 1st/99th); expanding-window percentiles or rolling z-scores; cross-sectional thresholds (month's own median) may be whole-sample, any time-axis threshold or fitted scaler must be re-estimated inside each training window; trailing-window scores with closes through t only (ch07, ch08, ch11, ch16, cs_usequities, cs_sp500eo, cs_usfirm).
- **Rolling windows crossing symbol seams** — an unguarded shift pairs one firm's return with another's / `.over("symbol")` on every shift/rolling expression; the library applies `.over(group_cols)` to every expression and refuses `group_col=[]` when an asset column exists (ch18, lib_engineer).
- **Contemporaneous flow features** — same-bar OFI correlation is mostly the definition of an up bar; TRF prints are delayed / `shift(1)`; compare same-bar vs lagged correlation and treat the gap as the size of the look-ahead; lag `order_flow`, `price_impact`, `hidden_liquidity` by one bar (ch03, ch08, cs_nasdaq).
- **Shared endpoint between feature and label** — a feature ending at p_t and a label starting at p_t share the same price, so noise in p_t enters both with the same sign: spurious covariance by construction / shift the label one session; treat failing cells as re-measure, not disproof (ch07).
- **Volatility estimator mismatch** — Parkinson/GK estimate within-session vol (read low vs close-to-close); ATR is a dollar range; VWAP minute prices understate RV; a 4-for-1 split reads as −75% / use close-to-close or Yang-Zhang for daily sizing, Parkinson/GK for intraday range; ATR for stops/normalisation only; last-trade prices, raw-bar open/close, XNYS calendar, flag |log return| > 0.25 (ch08, ch09).
- **Thresholds on relative volume** — a ratio cut selects different days than a log-volume z-score and does not transfer / write rules on the log-volume z-score; measure overlap; name transforms precisely (a rolling median is not a percentile rank) (ch08).
- **Lead-lag from stale closes** — a less liquid ETF closing before SPY fakes a lead / verify the leader traded at the lead timestamp (ch08).
- **Missing deferred contracts and carry** — carry becomes NaN; `x12` carry is a scale factor not an annual rate; panel heights mislead sign reading / require paired tenors, handle rolls explicitly, `carry_rank_sector`; count signs (ch08, cs_cme).
- **Options surface policy changes mid-backtest** — delta convention, interpolation, maturity mapping; IV read within a maturity window moves with expiration changes / contaminates every options feature / version construction choices with the features; keep the policy fixed; acknowledge DTE-bucket limitation (ch08, cs_sp500eo, cs_sp500opt).
- **VRP misread** — IV30 − trailing RV20 is not a vol-selling return; `garch_ivrv_spread` subtracts a 1-step forecast from a 30-day IV; mean and median disagree on sign under left skew / compute horizon-matched IV_t vs following-30-day RV; report share positive, mean and median; check every symbol > 50% positive; flag the horizon mismatch (ch08, cs_sp500eo).
- **Scaffolded fundamentals and integer month** — `market_cap = 2 x book_value` makes book-to-market constant; integer month implies Dec > Jan / `load_firm_characteristics()`; sin/cos encoding of phase, never post-event outcomes (ch08).
- **NaN vs null in Polars** — `drop_nulls` keeps NaN; `pl.corr` returns NaN on constant cross-sections; polars ranks NaN at the top; `walk_forward_feature` burn-in is NaN; one NaN makes a mean NaN / corrupted IC and ranks / replace non-finite with null up front (`fill_nan(None)`, `pl.DataFrame(..., nan_to_null=True)`), filter `is_not_null() & is_not_nan()`, convert NaN to null before writing so the all-null guard can fire; `cross_sectional_ic_mean` drops both (ch08, ch11, ch13, cs_cme, cs_crypto, cs_etfs).
- **Price-vs-return expression semantics** — passing returns to a price-reading expression (or vice versa) yields a plausible wrong column with no error; `garch_forecast`'s default omega and `fourier_features` period 390 (minute default) are wrong on daily data / returns: `realized_volatility`, `garch_forecast`, `rolling_entropy`, `rolling_correlation`, `beta_to_market`; prices: `ewma_volatility`, `volatility_of_volatility`, `volatility_percentile_rank`, `hurst_exponent`, `choppiness_index`, `market_regime_classifier`, `volatility_regime_probability`, `co_integration_score`; pass 252; neither `fourier_features` nor `rolling_entropy` is spectral entropy (ch09).
- **Spectral and entropy units** — spectral energy duplicates rolling variance (Parseval); raw `energy_period_*` counts volatility three times; entropy grows with bin count; even-window Nyquist bin; spectra of prices are trend-dominated; windows spanning a vol break average two regimes / normalise by total, half-weight Nyquist, use returns, require stationarity (ch09).
- **Warm-up rows populated inside their lookback** — a feature with a value before its window is full is reading something else; `sequence_dataset` maps null → 0.0 → the feature's mean after normalisation / `warmup_audit(per_entity, {ret_252d: 252, skip_recent_12_1: 252, sharpe_252d: 252, vol_252d: 252, dist_52w_high: 252, sma_ratio_200: 200, max_dd_126d: 126, hurst_100: 100, obv_zscore_63d: 63})` raises; `features.lookback(name, **params)` to trim; `explain_column_gaps` with declared prefixes (regime 756+21, garch 504+1) and residual 0; no warmup fallbacks; imputed burn-in rows printed (cs_etfs, cs_cme, cs_crypto, cs_fx, lib_engineer).
- **Holdout-withheld rebuild (seal) test** — any whole-sample transform, "including the ones nobody thought to flag", shows up as a value difference / one leaked moment contaminates every feature with nothing raising / `assert_values_agree(built.filter(ts < HOLDOUT), build_features(prices.filter(ts < HOLDOUT)), columns=feature_cols, keys=[timestamp, symbol])`; value-vs-null counts as a difference; equality is the pass condition; costs ~3 symbols of runtime and cannot pass by accident (cs_etfs, cs_fx, cs_sp500eo, cs_sp500opt, cs_usfirm, cs_cme, cs_crypto, cs_nasdaq).
- **Future-perturbation audit and its blind spots** — `audit_lookahead` (destroys inputs at `t > cutoff` with `nan`/`shuffle`/`noise` and flags any earlier feature moving by more than `max(noise_floor*5.0, 1e-9)`) catches smoothed HMM, full-sample PCA/autoencoders, full-window GARCH and time-axis z-scores / it does not catch same-timestamp label leakage or per-fold train/val seals; the level-vs-return leakage heuristic reads ≈ 0 even when leaking; leakage checks miss non-price leakage / use label checks and the splitters for the first two; compare both sides in return space; construction discipline for the rest (ch02, lib_diagnostic).
- **Coverage judged by nulls instead of owed keys** — a matrix emitting a thousand rows where a million were owed carries no nulls and is wrong / judge against `label_universe(CASE_DIR)` keys; classify missing keys leading/interior/trailing/absent against the gate's admitted fund-years; residual must be 0; declare `quality_report` causes and print the unexplained residual (1,068 keys, 1.0%) rather than explain it away (cs_etfs, cs_crypto).
- **Contemporaneous answer columns in the matrix** — `open, high, low, close, volume, log_return` (the model's own answer), raw close or `premium_index_close` beside the label / exclude; `null_policy` only on declared columns (`drop_nulls(subset=["sharpe_126d"])`); assert no duplicate (timestamp, symbol) (cs_etfs, cs_crypto).
- **Shared construction helpers and conventions** — an earlier rolling sum/std * sqrt(252/w) inflated Sharpe features by sqrt(w) in four case studies; `max_dd_{w}d` is current drawdown vs trailing max; Wilder vs SMA smoothing / use `momentum_volatility_block` and `ml4t.engineer.features`; read every window/lag from `case_studies/<cs>/config/setup.yaml::features` (`families_from_config`), never retype (cs_etfs).
- **Persistence for the decision cadence** — a feature must hold its ordering ≥ one decision cycle (21 sessions) to be usable monthly: 6-month features (cross-rebalance rank corr ~0.83) qualify, 1-month return (~0) does not; measure rank autocorrelation before modeling (ch06, cs_etfs).
- **Market-level columns in cross-sectional models** — yield-curve slope, regime duration, HMM dollar-regime, `funding_session`, `xs_funding_dispersion` take one value per date so cross-sectional IC is NaN and top-k selection breaks / ensure cross-sectional signal varies across assets; `MARKET_LEVEL_SHARE = 0.90` screen → REVISE; per-date std < 1e-10 → REVISE never IC 0; keep them for interactions; `.filter(ic.is_finite())`; count distinct values per date (ch12, cs_fx, cs_crypto, cs_cme, cs_usequities, cs_etfs).
- **Windows counted on sparse rows; null policy as hidden screen** — `shift(21)` on a sparse panel is 21 quotes; requiring `iv_mom_10d` drops every symbol quoted in bursts; a 252-session z-score from 202 quotes is a different statistic / `on_session_grid` inside `sec_id` then `.shift(IV_LAG)` and a 5-session forward fill; `null_policy: [vrp_21d, rv_21d]` only; print what stricter policies cost (cs_sp500eo, cs_sp500opt).
- **Suspension gaps and unbroken runs** — shift, FFD convolution and GARCH recursion read a months-long gap as consecutive sessions; a listing/halt jump reads as one day's move / measure gap frequency; window sequence models only over unbroken 60-session runs; gap-safe eligibility grid; report example counts per fold (cs_usequities, cs_fx).
- **EPS floors and percentile formulas** — EPS must be in the variable's units (bps-scale variances need positivity guards); `ZERO_FLOOR = 0.001`, `risk_adjusted_vol_floor: 0.01`; percentile = `rank / (count + 1) * 100` so top of 3 and top of 19 differ on an unbalanced panel; clip vol ratios at 10, carry z at ±5, `EPS = 1e-8` (cs_crypto, cs_sp500eo, cs_cme).
- **Feature families and registration** — every column registered in exactly one family `pattern`; composites recomputed by a second route; a schema inventory is not a contribution and a grown `FAMILY_TOKENS` matches everything / identifier columns inflate feature counts; subtract `_ID_COLS` (inference) (ch08, ch09, cs_usfirm).
- **Composite and conditional constructions** — a composite scoring four gates lets a strong signal outvote a failed gate; conditioning on a variable derived from the signal fabricates regime dependence / keep hard gates separate; pre-defined clean conditioning variable (42-day SPY RV) with expanding-window tercile thresholds (ch04, ch08).

### 5b. Model-based features

- **Fitted on the whole sample or inside a CV fold** — GMM/HMM/GARCH/ARIMA/Kalman/centroids/PCA/factor loadings fitted on all history assign values informed by later dates ("not a rule that could have been applied in 1929"); fold-wise fitting gives training rows parameters from their own future and validation rows not, with nothing raising ("a schedule bounds an estimate; a fold selects rows") / `walk_forward_feature(X, timestamps=, burnin=, refit_every=, fit=, apply=, n_features=, freeze_after=, on_fit_error="skip")` with no `fold` column; burn-in 504 GARCH / 756 regime, refit every 63 (21 for options), `LOOKBACK=1260` / `REFIT_EVERY=63` for breaks; stamp from the last completed refit; parameters from strictly earlier sessions; fit factors, loadings and the IPCA mapping inside each training window (ch01, ch09, ch14, cs_etfs, cs_fx, cs_sp500opt, cs_usequities, cs_crypto, cs_cme).
- **Smoothed instead of filtered inference** — hmmlearn `predict_proba`/`predict` (Viterbi), Kalman smoothers and wavelet components read future observations; smoothed probabilities rise before transitions / `filtered_state_probs` forward recursion only; measure the share of sessions where filtered and smoothed disagree; DWT only to pick scales then rolling features at `SCALE_TO_WINDOW` (ch09, cs_etfs, cs_fx, cs_crypto, lib_diagnostic).
- **Rolling-window stamp alignment and window-length selection** — a window containing the stamp date leaks that session; a signal length chosen on the whole sample is a leaked parameter / end each window the session before the stamp; estimate half-life on the first 50% only; `rolling_rank` with trailing `REGIME_WINDOW=252` instead of whole-history ranks (ch09).
- **Library recursions reading the whole array** — `arch`'s `.fix()`/`conditional_volatility` derive residuals, backcast and variance bounds from the full series (128 of 1,500 shared rows moved by up to 0.064%); `apply(endog, refit=True)` is an in-sample fit masquerading as a forecast / write the GARCH recursion by hand with `garch11_conditional_volatility(r, mu, omega, alpha, beta, backcast)` from the estimation window; `arima_one_step_forecast` with `refit=False` and assert params moved by 0; never `forecast(h)`; GARCH backcast/bounds from the training fit, advance one step (ch09, cs_etfs, cs_usequities, cs_sp500opt, cs_cme, cs_crypto).
- **Refit schedule seals and freeze at the holdout** — fits that end inside the holdout; an empty holdout satisfies "no leak" vacuously and makes a holdout retrain fit on nulls / `refit_boundaries` puts every emitted index at or after its block's `fit_end`; assert every `fit_through < HOLDOUT_START` AND holdout-dated rows are populated; `freeze_after = pre-holdout session count`, assert `fit_end.max() <= freeze`; `n_refits <= len(scheduled)`, `last_fit_ends < holdout_start`; filter `timestamp <= HOLDOUT_END` so a refreshed price file cannot widen the artifact; holdout values age under frozen parameters (state it) (cs_etfs, cs_cme, cs_crypto, cs_usequities).
- **Truncation (causality) test** — "deleting observations after a session must not move that session's value"; multithreaded numerics break seeds / cut one series at `fit_end + refit_every//2` (inside a block), re-walk, `np.testing.assert_allclose(short, full[:cut], rtol=1e-12, equal_nan=True)`; delete the last year and check every surviving value; check that the leak check can fail (nearly empty under a refit schedule) (cs_etfs, cs_fx, cs_crypto, cs_cme, cs_nasdaq).
- **HMM/GMM estimation hygiene** — single EM start stops at a local maximum (ARI as low as 0.73); state 0 changes meaning across refits; parallel reductions move probabilities ~1e-11 and the digest (five thread counts gave five log-likelihoods); state count by in-sample BIC always finds more clustering; tiny clusters (3–8 months) cannot be named / `fit_hmm_restarts(X, n_states=2, random_state=0, n_restarts=10)` (k-means init, `init_params="st"`, covariance ridge 1e-6), `n_init=10`; `sort_states_by_variance` / `sort_states_by_mean` / `order_by_dispersion` and assert the higher label has higher spread; `threadpool_limits(limits=1)`; two states (calm/stressed) as a stated judgement; `np.bincount(labels).min()`; compare partitions with ARI; publish a perturbation table across seeds; `StandardScaler` before any distance-based method; selection criteria disagree (BIC → 2, silhouette → 2, AIC → 6: choose by purpose, report switches and smallest cluster); pooled 2.23x vs rolling 1.30x volatility ratios answer different questions, report both; assert `N_REGIMES_SELECTED` is in `N_REGIMES_GRID`; naming-rule thresholds set for the post-2002 US do not transfer (ch01, ch09, cs_etfs, cs_crypto, cs_cme).
- **Regime label semantics** — a mixture has no time structure (267 switches in 97 years, risk-off mean 2.1 months); acting on a label that flips several times a year pays costs on every switch; macro regimes arrive with or after the event (Feb 2009 sits in "Recovery"); `regime_transition`/`regime_log_duration` computed per block instead of over the emitted series; state numbers not comparable between fits / use HMM with transition structure for persistence; label as a risk lens tied to predefined actions, never a forecast; derive derived regime series over the WHOLE emitted series; prefer `wass_dist_ratio` over state labels; pair centre-shift regimes with dispersion features (inference) (ch01, cs_etfs, cs_usequities).
- **GARCH preconditions** — fitting on fractional returns is badly conditioned (multiply by 100, omega then in percent²); no ARCH effect means nothing to model; persistence ≥ 1 leaves long-run variance undefined; normal innovations under-cover (switch to Student-t); alpha + gamma < 0 for 19.0% of securities on the first 252-session block vs 1.8% walk average / `arch_lm_test` first; `MIN_OBS = 252`, never fit below a year; read `garch_omega` warnings from `SyntheticProvider` (ch05, ch09, cs_sp500eo).
- **FFD order and boundary values** — order searched on the evaluation sample (even one grid step triggered by a full-sample test); boundary-partial values are a silent regime change; `find_optimal_d` / `fdiff_diagnostics` run boundary-partial and can pick a width exceeding the sample / fix `ASSET_CLASS_D` or `search_d_on_training` on the 80% cut; null the first `width − 1` rows and publish the mask and sample loss (ch09).
- **Kalman and pairs identification** — level vs slope variance nearly flat; hedge-ratio observation variance from the whole pair; CUSUM/MOSUM references re-estimated / `LOG_BOUNDS` and report refits on the floor; `PAIR_OBS_VAR` from a static OLS on `HEDGE_BURN_IN=252`, hold beta_{t−1}, expanding spread band; fix mean and scale on `BURN_IN=252`; `kalman_smoothness` is a near-constant state, not a cross-sectional signal (ch09, cs_fx).
- **Stationarity and break tests** — both-reject ADF/KPSS read as "trend"; 0.01/0.10 are KPSS table limits; a break inside a window gives rejection without location; mean-shift segmentation on price level finds drift not crashes; synthetic-calibrated detectors score nearly every real window positive / `strong_stationary` only when ADF/PP reject and KPSS fails to reject; segment returns/volatility; label real history against dated events; a quarterly refit is blind to a break for a quarter (shorten `REFIT_EVERY` or pair with MOSUM) (ch09, lib_diagnostic).
- **Uncalibrated or misread statistics** — Fisher-combined p-values from overlapping windows, F-tests on returns, `coefficient_of_variation` on raw returns, Hurst without R² (library on prices vs manual on returns differ), OLS SEs on volatility regressions (use HC3 + NW22), negative HAR coefficients (collinearity, read the three together), daily HAR refits (noise), multi-step ARIMA (decays to mean), ranking return models on RMSE (a constant forecast wins; use rank IC), selecting on the reported metric (select on AIC, report IC) (ch09).
- **Bayesian/SV posteriors** — divergences, R-hat > 1.01 or ESS < 200 mean the mean is not the posterior's; nu posterior bounded below at 2; back-transforming a log-scale sd; carrying a quarterly posterior level between refits / gate on R-hat, bulk/tail ESS, divergence count; retry longer, fail rather than lower the bar; exponentiate endpoints only; carry parameters per refit, take the level from GARCH (ch09, cs_sp500opt).
- **Volatility feature semantics** — persistence as a cross-sectional feature (every liquid symbol just below one), raw vol level as conditioning (moves an order of magnitude 2012–2020), unsmoothed term-structure ratios, `expected_duration` per session, interval width scaling with level, HAR variance forecasts extrapolating negative / percentile rank or HAR ratio; smooth over a month; `log_forecast_std` and `median_forecast` with coverage check; model log-variance; vol-model premium columns lag IV (ch09, cs_nasdaq, cs_sp500opt).
- **Cointegration misuse** — correlation is not cointegration; trading the Johansen ratio with no cointegration; screening six pairs at 0.05; a rolling cointegration score is a window description; high return correlation does not make a price ratio stationary / demand it hold on unseen data; inspect ratio and z-score panels; count state-machine transitions; negative phi gets no OU half-life (ch09, ch14, ch16).
- **Signatures** — min-max before signatures makes the cumsum monotone; dimension O(d^depth) (10 assets at depth 4 = 303,600); unnormalised levels O(1/k!); full signature redundancy; omitting the time coordinate collapses rise-and-return; overlapping-window leakage / z-score normalisation; 1–5 assets at depth 4, `compute_sig_dim_paper`; multiply level k by k!; log-signature; purge `WINDOW_SIZE + FORECAST_HORIZON − 1` = 24 rows; normalise against the window's first observation (ch05, ch09).
- **Regime-conditional and interaction columns** — `feat_bear/neutral/bull` sit on unsigned −1/0/1; non-zero interaction values are not regime counts; mixture of experts with thin regimes; near-zero regime importance misread / assert the pairing; report session counts per regime; require 20 training rows per expert; `volatility` already carries the information (ch09).
- **Kernel width and clustering comparisons** — MMD collapses far from the data scale; inertia/silhouette flatter their own geometry / median heuristic from 2000 pairs (print sigma); MMD plus adjusted Rand where truth exists; validate unsupervised separation downstream and carry `cluster_distance`; Ward linkage assumes Euclidean geometry (`HierarchicalClusterer` enforces it), so on correlation distance use complete (or average) linkage — complete avoids chaining on moderately correlated panels (ch08, ch09, lib_diagnostic).
- **Refit cadence and staleness as declared costs** — estimates held fixed between refits (quarter for Kalman/HMM, month for ARIMA; holdout params frozen up to 2 years); refits may buy nothing / print burn-in counts; refit-jump diagnostic (jump across a refit session vs ordinary one-day move); expanding windows keep a structural break forever (left open) (cs_fx, cs_sp500opt, cs_etfs).
- **Process-pool and determinism details** — Python 3.14 defaults to forkserver which cannot reach notebook functions; `Series.unique` order undefined / explicit fork context, `workers = min(len(payloads), cpu_count−1)`; fix ordering then `set_global_seeds(SEED)`; verify two runs agree to the digit (ch05, cs_etfs).

### 5c. Text and NLP features

- **Embedding geometry misread** — co-occurrence places `profit` and `loss` together; numeric/currency tokens (`eur4`) pollute neighbours; t-SNE distorts edge points; analogy arithmetic undefined on small corpora; averaged vectors lose order and negation scope / check the opposite word in the neighbour list; normalise numbers to a placeholder and inspect the top-15 tokens; test cosine in native space; use sequence models or contextual embeddings; `workers=1` for deterministic Word2Vec (ch10).
- **Stop words deleting negators** — `stop_words="english"` removes `not`, `no`, `never`, `nor` so "profit did not rise" == "profit did rise" / inspect the stop list; keep negators (ch10).
- **Checkpoint contamination and mismatched comparisons** — a checkpoint fine-tuned on the test corpus; before/after across different checkpoints (`finbert-tone` vs `ProsusAI/finbert`); label order mismatch by index; kept pretrained head with permuted labels / carry provenance; same checkpoint on both sides; map labels by name and assert; align or re-initialise the head (ch10).
- **Classification metrics** — accuracy on imbalanced classes hides a never-predicted class; the zero point for skill is the majority rate not 1/k; confusion matrix says what not why; 1–2 point differences on a few hundred sentences are seed noise / macro F1 + confusion matrix + misclassified examples; print class balance; also call `transformers.set_seed(SEED)`; `DataCollatorWithPadding` (ch10).
- **NER** — synthetic split not held out (birthday-problem copies); subword alignment errors; token-level vs entity-level metrics; counting non-`O` tokens / count shared token sequences; first subword gets the label, rest −100; `seqeval` entity-level F1; count `B-` tags (ch10).
- **Asset-embedding evaluation** — duplicate holdings within a filer; averaged bucket rates or CI endpoints; bootstrapping positions instead of portfolios; beating uniform random; re-derived baseline trials; co-holding ≠ similar performance / collapse to max per (cik, stock); pool over masked positions and bootstrap pooled outcomes; resample by portfolio; add the top-5-most-held popularity baseline on the same hit records (ch10).
- **News-signal timing and dedup** — wire-service syndication counts one story many times; news after the close used for t→t+1; calendar-day lag joined on equality drops Friday stories; event-day lookback reaches back years for thin tickers / dedup (exact + 50-char prefix hash within ticker-date); lag 1 day with the surprise baseline on t−20..t−1; `join_asof(strategy="forward")` to the next session; state coverage-conditioned selection (ch10).
- **Filing-signal joins** — backward as-of attaches text to a close that preceded it; same-date multi-quarter filings fan out joins; rows without cluster id; 10-K truncation at 512 tokens (~380 words vs ~9,500-word MD&A); one calendar quarter per year has ~1/5 the filings because Q4 is in the 10-K / `join_asof(strategy="forward")` keyed on acceptance date; `unique(subset=["symbol","filing_date"], keep="last")` after sorting by `period_end`; chunk at 1500/1200 chars with `truncation=True, max_length=512`, mean-aggregate; carry `sentiment_std`, `pos_pct`, `neg_pct`; rank cosine distance relative to boilerplate base rate; condition seasonal analyses on form type (ch10).
- **Text-signal inference** — pooled observations across dates masquerade as accuracy; unequal quantile buckets from ties; overlapping 5d/20d ICs autocorrelated; bucket spreads quoted without intervals or annualised; ranking signals whose statistics are all ~0 / one IC per date; check per-date bucket sizes; Newey-West or block bootstrap; cluster bootstrap on symbol (`N_BOOT=1000`, `MIN_VALID_BOOT=200`, `_pooled_spearman` NaN for n<5) as a screen with 15 pairs treated as multiple testing (inference); deterministic universe cut sorted `["len","symbol"]`; per-pair seeding (inference); `MAX_SYMBOLS` trades coverage, `TOKENIZERS_PARALLELISM=false` (ch10).
- **Text extraction** — hard-coded 10-K item numbers on a 10-Q (MD&A is Part I Item 2); first heading match hits the ToC; boundary overrun; flattened paragraphs; amendments in a consecutive pair; comparing a failed extraction; company + date as key / pattern set by form with `after` marker; longest-span rule; word count ≤ 50,000; `get_text(separator="\n")` with ≤ two blank lines; `amendments=False`; compare only `quality == "ok"` without `boundary_leak`; key on accession number (ch04).
- **Form 4 and insider parsing** — regex over text pairs one trade's code with the next's price; silent `continue`; first `<reportingOwner>` only; missing price as zero; dtype inference on first rows; all rows as signal; unweighted netting / walk the XML tree per `<nonDerivativeTransaction>`; count incomplete blocks and reconcile; collect owners with `n_owners`; `price=None`; declare `TRADE_SCHEMA`; gate on P/S codes; weight by priced value per insider and direction; try/except per filing with `parse_error` (ch04).
