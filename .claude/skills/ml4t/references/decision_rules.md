# Decision rules and defaults: the book's numbers, thresholds and sequencing, stage by stage

> Every concrete rule, numeric default, threshold and ordering rule the ML4T 3rd-edition notebooks and the six `ml4t-*` libraries fix, grouped by workflow stage. Use it to pick a default before you invent one, to recognise a pre-registered gate, and to find the detailed reference (the Source column names the chapter `chNN`, the library `lib_<name>` = `libraries/ml4t_<name>.md`, or the case study `cs_etfs`, `cs_crypto` (crypto_perps_funding), `cs_nasdaq` (nasdaq100_microstructure), `cs_sp500eo` (sp500_equity_option_analytics), `cs_usfirm` (us_firm_characteristics), `cs_fx` (fx_pairs), `cs_cme` (cme_futures), `cs_sp500opt` (sp500_options), `cs_usequities` (us_equities_panel) = `case_studies/<full name>.md`; the same legend as `evidence.md`). Conventions, not laws: a value marked "convention" or "placeholder" sets an order of magnitude and must be calibrated per instrument. Items marked "(inference)" were inferred by the note-takers, not stated in the repo.
